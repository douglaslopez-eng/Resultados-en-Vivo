# 🏃 AtletismoPro — Resultados de Atletismo en Vivo

**AtletismoPro** es la plataforma de consulta de resultados de competencias de atletismo en tiempo real. Accede a marcas, clasificaciones, medallería y programa de eventos.

🌐 **Sitio web:** [https://atletismopro.onrender.com](https://atletismopro.onrender.com)

## ¿Qué puedes consultar?

- 🏅 Resultados de competencias de atletismo
- 📅 Programa de eventos y horarios
- 🌱 Siembras (orden de salida)
- 🏆 Medallería por club/delegación
- 👥 Participación de clubes

## Palabras clave

atletismo pro resultados, atletismo resultados en vivo, competencias atletismo, marcas atletismo, atletismo centroamerica, atletismo guatemala

## Tecnología

- Python 3.11
- Streamlit
- SQLite / Supabase
- Hospedado en Render.com
